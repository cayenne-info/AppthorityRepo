Remove from Whitelist or Blacklist

Select options in Remove from Whitelist:

  • Apply to selected app versions only - Remove only the selected app versions from the whitelist.
  • Apply to all versions of selected apps - Remove all versions of selected apps from the whitelist.
    Note: This also removes any apps that are set to auto-whitelist.

The same options apply to blacklisting options in Remove from Blacklist.

Note: The option Apply to all versions of selected apps also removes any apps that are set to auto-blacklist.

Enter API Authentication

You may need your EMM administrator to provide this information.

Use the Authentication panel to enter your AirWatch credentials.

To use Connector Cloud, go to Admin > Organization; under Appthority Connector, click Cloud.

To authenticate with your API

  1. Enter the host and port used by your EMM API.
  2. Enter a username and password for a user with API privileges.
  3. Enter your API key (for AirWatch only).
  4. Click Validate to test your API connection. This is only available when all the required information has been entered. Appthority will display this once credentials are authenticated:
  5. Click Save Changes.

Set Up Your Organization

Use the Admin > Organization sub-tab to configure EMM settings and Appthority Mobile Agent options for your organization.

Tip: See EMM Overview Workflow for end-to-end steps to implement EMM functionality in Appthority.

The options available change depending on your selection. When you select a vendor, only the products for that vendor are available in the product menu.

For both EMM and Mobile Agent sections, if you select Enable, you must select an option beneath.

Note: Make sure to click Save Changes whenever you make a change to the Organization or EMM sub-tabs. The button is available only when all required info on the page is completed and there are unsaved changes.

Once you have an active Connector, some changes are not available. If Save Changes is available, a confirmation dialog will display for Organization and EMM changes that would rarely be changed after initial setup.

Using Common Features

These features are common to many sections in Appthority Portal.

Some tabs display a set of options on the left. Use these as filters to view or manage specific apps, devices, and policies.

Click one or more options or filters in the left panel to see the results in the main section.

For example, to see all apps or devices not compliant with a specific policy, select it to show matching results in the main section.

  • The number of apps or devices impacted is indicated in parenthesis. Click the number to open the corresponding page with the results.
  • A green dot indicates an active policy; a gray dot indicates an inactive policy.

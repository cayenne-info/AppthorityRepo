Deploy Mobile Agent

Use the Mobile Agent sub-tab to manage Appthority's Mobile Agent for your organization's devices.

Note: You must select Enable Mobile Agent in Admin > Organization sub-tab to enable the Admin > Mobile Agent sub-tab.

Note: Only platform options selected under Organization > Enable Mobile Agent will appear in Deploy Mobile Agent.

Access the Mobile Agent options from Admin > Mobile Agent. A few options on this screen change depending on which deployment type you select. The deployment types available will be the EMM used by your organization, or Appthority if you want to deploy Mobile Agent without EMM integration.

Select your deployment type from the menu and use the links to view instructions and perform script and certificate actions. Note the options in this menu are determined by your Organization settings.

See iOS Agent Actions for options common to all pages for iOS.

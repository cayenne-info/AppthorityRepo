Mobile Agent: MobileIron

Select MobileIron for Mobile Agent Deployment Type if you use MobileIron EMM.

Note: You can also deploy Mobile Agent without EMM integration. To use this option, select Appthority.

Access this option from Admin > Mobile Agent once you have configured your organization.

Follow the steps to configure your Android or iOS Mobile Agent.

To configure Android app for MobileIron

  1. Email support@appthority.com for your Appthority Org ID. You may also need your plist file or shared secret.
  2. Download the Appthority configuration app from the link.
  3. Click Download for the Android Agent.
  4. Configure your MobileIron settings. See MobileIron: Deploy Android Mobile App for instructions.

To configure iOS app for MobileIron

  1. Email support@appthority.com for your Appthority Org ID. You may also need your plist file or shared secret.
  2. Click Download for the iOS Agent.
  3. See Signing the iOS Appthority Mobile App for instructions on how to sign your iOS apps.
  4. Set up Mobile Agent in MobileIron. See MobileIron: Deploy Mobile Agent for instructions.

See iOS Agent Actions for details of the options on this page.

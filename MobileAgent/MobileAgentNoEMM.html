Mobile Agent: No EMM

Select Appthority for Mobile Agent Deployment Type to deploy Mobile Agent without integration with an EMM. You can choose this option even if you use an EMM for other integration.

Access this option from Admin > Mobile Agent once you have configured your organization.

For Android, tell Support you want the Android Mobile Agent. The link will appear under Mobile Deployment Sites when available - simply copy the link you want (released or beta) and send to users to install on their devices.

For iOS agent, you must first sign the app. Once the iOS app is available, the link will work for both platforms - when a user clicks the link you send them, the correct version will be installed on the user device.

To sign the iOS app, choose one of these options:

  • See Signing the iOS Appthority Mobile App for instructions on how to sign your iOS apps.
  • You also have the option to create an Apple Developer Enterprise account for Appthority and allow us to handle signing your app. Contact Appthority to set this up.

Once you have uploaded the re-signed app, contact Appthority Support, and notify them that your re-signed app is uploaded. Within 24-48 hours, the URLs will be available under Mobile Deployment Sites.

Provide your users with the URL listed under Latest or Beta Release.

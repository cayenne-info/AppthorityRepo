Manage Remediation Actions

Use Remediation Actions to manage the Actions available for remediation, and to add new actions.

Access these options from Compliance > Remediation Actions.

  • To see the components and a description of an action, click Preview.
  • To create a new action based on an existing one, click Copy and Create New.
    • Click Add Action to add actions, or click to remove actions.
    • Rename the action and make your changes, then click Create Enforcement Chain.
  • To edit the email template for an action, click Edit Email Template and select the template. Note this is only available for 'Warn' actions (that send emails).
    • In Email Template, make the changes you wish and click Update Template.

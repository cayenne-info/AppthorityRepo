Behaviors: Best Practice

Appthority offers the ability to assess and manage risk to your enterprise through comprehensive app analysis combined with creating policies. This section offers some example app groupings that we recommend, aligned with NIST Special Publication 800-163. Configure these as app policies to identify risky apps in an organization, and to protect against these vulnerability types.

Category Behaviors
Malware/Spyware
  • Malware Detected
  • Is a Spyware
  • Attempts Root Device
  • Infected by XcodeGhost
  • Infected by Dresscode
  • Infected by Exaspy
  • Uses YouMi SDK
  • Uses mobiSage SDK with Backdoor
High Risk (Android)
  • Accesses Telephony Service
  • Calls Exec When Running
  • Reads Installed App Names
  • Changes Device Configuration
Permissions and Privacy
  • Accesses Address Book
  • Accesses Calendar
  • Has Permission to Place Calls
  • Has Permission to Record Calls
  • Has Permission to Bind Device Admin
  • Stores credentials unencrypted
Exposed Communications
  • Access Telephony Service
  • Accesses Bluetooth Sharing
  • Accesses Microphone
  • Access SMS Archive
  • Sends SMS Messages
  • Disables the SSL CA validation
  • Does not enforce HTTPS connections
Data Exfiltration
  • Sends Address Book
  • Sends Calendar
  • Sends IMEI
  • Sends UDID
  • Sends Location
  • Sends credentials unencrypted
  • Sends the device's name
Potentially Dangerous Functionality
  • Calls Exec When Running
  • Uses Hardcoded Credentials
  • Changes Device Configuration
  • Writes the APN Settings
  • Uses JS Patch for hot patching
  • Uses Aggressive Adware
  • Detects if device is rooted/jailbroken
  • Keyboard Extension with OpenAccess
  • Performs direct system calls
  • Performs dynamic symbol lookups
  • Prevents device from locking screen
  • Reads data from the Clipboard
App Collusion
  • Creates and Advertises a Service
  • Creates Listening Ports
  • Gaming app that accesses the Address Book
    • Accesses Address Book
    • Category: Games
  • Phishing attack 1 – Collects Employee Communication Data
    • Accesses Call Logs
    • Accesses SMS Archive
  • Phishing attack 2 - Collects Employee Schedule/Activity Data
    • Tracks Location
    • Sends Calendar
  • Handles Custom URL Schemes

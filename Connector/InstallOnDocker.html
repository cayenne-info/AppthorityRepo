Install Using Docker Host

To install the Appthority Connector using your Docker host environment, have your Docker administrator follow these instructions. The Docker administrator may be the same as your Appthority administrator.

Note: If you need to install Docker first, follow these instructions.

To install Connector on Docker

  1. Log in to your Docker host.
  2. Run the command (you can copy and paste it).
    curl -Ls http://connector.appthority.com/appthority.sh> appthority.sh ; chmod +x appthority.sh ; ./appthority.sh
    This will download and run the script to install the Connector image on your Docker host.
  3. Step through the script in the command line or terminal app.

Install Docker on RedHat

If you want to install Connector using a Docker host on your own RedHat VM, follow these steps.

Install Docker

The basic steps and exact commands to run are here. Refer to the detailed instructions for more information.

To install Docker on RedHat

  1. Run this command to install Docker on RedHat
    curl -fsSL https://get.docker.com/ | sh
  2. Add user 'appthority' to 'docker' group (run as root):
    useradd appthority
    usermod -aG docker appthority
  3. Run the command to start Docker at boot (run as root):
    systemctl enable docker

Next: Install Connector

Note: When you install Connector, it is recommended that you use an account called 'appthority' that has access to the Docker group.

Deploy VM Appliance

To install Appthority Connector using the downloaded VM Appliance, have your VM administrator follow these steps. The VM administrator may be the same as your Appthority administrator.

Note: Deploy the VM Appliance using your virtual machine admin tool instructions. Once the VM is correctly configured, continue to these steps.

To register your RedHat instance, you must subscribe and agree to their terms. Configure your Red Hat licensing to open the Appthority image the first time you log in. The VM is in RedHat Enterprise Linux version 7.3.

Appthority creates two user accounts, 'root' and 'appthority'.

To install Connector on the VM Appliance

  1. Log in to the Virtual Machine as appthority user.
  2. Run the command (you can copy and paste it).
    curl -Ls http://connector.appthority.com/appthority.sh> appthority.sh ; chmod +x appthority.sh ; ./appthority.sh
    This will download and start the script to install the Connector image.
  3. Step through the script in the command line.

Configure EMM Connector

Use these guidelines to configure Appthority's EMM Connector to integrate with your EMM.

Tip: See EMM Overview Workflow for end-to-end steps to implement EMM functionality in Appthority.

For MobileIron, a legacy option for EMM integration exists that does not use Appthority's Connector.

Access these options from Admin > Organization > Enterprise Mobility Management in Appthority Portal.

To see what data Appthority collects and how it uses the data, see Appthority Data Privacy.

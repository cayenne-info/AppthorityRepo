Configure Connector Cloud

If you choose Connector Cloud for your EMM integration, your Appthority instance is deployed with Connector Cloud. When you enter and validate API authentication, Connector Cloud is activated and displays as Active on the Admin > Organization page. It is then ready for configuration, and these instructions apply.

See Enable EMM Integration for more information on these steps.

To use Connector Cloud, go to Admin > Organization; under Appthority Connector, click Cloud.

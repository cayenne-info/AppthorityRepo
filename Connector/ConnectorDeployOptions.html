Connector Deployment Options

Appthority provides cloud or on-premises options to deploy and configure EMM Connector for some EMMs.

Connector Cloud
Use Connector Cloud to integrate to EMMs that are deployed either as SaaS or on dedicated hosting. Appthority deploys Connector Cloud automatically when your Appthority instance is set up. To configure Connector Cloud, you only need to enter your EMM API host and port, API credentials, then select the integration options to use once Connector displays Active.

Tip: You can also use Connector Cloud with an EMM on-premises. To do this, you must also whitelist Appthority's IP address (184.169.173.217) and open port 443 in your EMM.

Connector On-Premises
Use Connector On-Premises to integrate with EMMs that are deployed inside your datacenter environment. Connector On-Premises is deployed in the same environment as your EMM instance, and requires a virtual host to run.

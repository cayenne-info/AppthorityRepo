Set Up Your EMM

Use these instructions and support articles to set up your EMM with parameters specific to Appthority. This allows Appthority to communicate with your EMM.

You will need some information from your EMM administrator to deploy Appthority Connector. Have these details on hand before you proceed to the other steps:

  • The host and port used by your EMM.
  • API keys to access your EMM.
  • User name and password for an EMM user with API privileges.

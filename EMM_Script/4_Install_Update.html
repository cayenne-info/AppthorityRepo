Install or Update Connector

4. install - Install or Update Connector. Gets Connector image and installs new Connector or updates existing Connector, if there is an update.

NOTE: You cannot update an instance that is running. Use the ‘k’ command to first kill the instance you want to update. Commands apply to the running instance displayed at the top of the script commands.

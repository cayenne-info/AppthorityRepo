Run EMM Deployment Script

Step through these command-line options to complete the Appthority Connector on-premises deployment. Whether you use a VM Appliance or Docker to set up Appthority Connector, you must do these steps. Again, to download and run the script, either for VM Appliance or from Docker:

curl -Ls http://connector.appthority.com/appthority.sh> appthority.sh ; chmod +x appthority.sh ; ./appthority.sh

Tip: See EMM Overview Workflow for end-to-end steps to implement EMM functionality in Appthority.

To run commands

  • Enter the number for each action you want, then enter the information. You should normally go through the steps in order.
    When [Okay] displays, hit Return again to make the next selection.
  • Commands are not case-sensitive. You can use the first letter or type out the command.
  • Enter ctrl + c at any time to send a break and exit the current step.

See additional options for more commands. If you are installing multiple Connector instances, you will need to use these options.

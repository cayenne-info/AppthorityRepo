Appthority Data Privacy

Organizations want to know exactly what data is shared with Appthority and its direction of travel. Details for the various implementations and configuration options are explained here.

Terminology and Products

  • Appthority Connector - Appthority EMM solution to communicate between your Appthority and EMM environments.
    • Connector Cloud - Connector deployed to Appthority Cloud. You can use Connector Cloud with an EMM either in the cloud or on-premises.
    • Connector On-Premises - Connector deployed behind the customer firewall. You can use this option only if your EMM is deployed on-premises. Appthority Cloud communicates with Connector On-Premises, and does not access your EMM directly. Remediation calculations are done behind the firewall.
  • Appthority Portal - The Appthority web solution in the cloud where you manage your Appthority integration with your EMM.
  • Appthority Cloud is the back end for Appthority’s web UI, as well as for Connector if you're using the cloud version.
  • Mobile Agent - Appthority mobile app installed on your employee mobile devices.
